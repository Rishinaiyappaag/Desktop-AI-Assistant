## 🧠 Desktop Voice Assistant<br>
A voice-activated desktop assistant built using Python. It can perform tasks like telling time/date, searching Wikipedia, taking screenshots, opening websites and applications, playing music, and even remembering things you tell it!

## 🔧 Features
🕐 Tells the current time and date<br>

🗣 Greets the user based on the time of day<br>

🌐 Searches Wikipedia<br>

📂 Opens YouTube, Google, StackOverflow, Wikipedia, Chrome, Calculator, and local folders<br>

🎶 Plays random music<br>

🖼 Opens images<br>

📸 Takes screenshots<br>

🔍 Accepts search queries to search on Chrome<br>

🧠 Remembers user input and can recall it later<br>

👂 Uses voice recognition for commands<br>

🗣️ Speaks responses using text-to-speech<br>

## 🚀 Getting Started
🔩 Prerequisites
Make sure the following Python libraries are installed:<br>
pip install pyttsx3 SpeechRecognition wikipedia pyautogui pyaudio<br>
Also ensure:

pywin32 is installed (can be installed using pip install pywin32)<br>

You are on Windows (for .lnk files and os.startfile usage) <br>

## 🎙️ Required Hardware<br>
Working microphone <br>

Speakers for audio output<br>

## 🧠 How It Works
The assistant greets you based on the time of day.<br>

It listens for your voice command via microphone.<br>

Executes tasks based on recognized commands.<br>

Uses Google’s Speech Recognition API to understand your voice. <br>

Responds via text-to-speech using pyttsx3. <br>
